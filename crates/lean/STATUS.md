# lean: status

Works: one lemma per solver row (`C_i → tag(old) = A ∧ tag(new) = B`, fixed `simp_all` script), one coverage lemma per unit, fold lemmas `W.run_nothrow`/`W.run_refines`; each theorem judged by `lean --json` (no error, no `hasSorry` in its span) and `#print axioms` (only propext, Quot.sound, Classical.choice); 30 s per theorem, 1.5 GB; model-written proofs, 3 attempts.
Two emission modes, chosen by the rows:
- Differ mode (`declarations` contain `(declare-sort Obj 0)`, i.e. `crates/differ` output; `src/mirror.rs`): models are emitted in the differ's vocabulary (one sort `Obj` with `w_null`, `w_len`, `w_at`, `w_is_<T>`, opaque names as declared). Literals translate to Lean syntactically, so the bridge is not used. Paths collect reports, effect calls (unit result) and throws, and the tag follows the differ: throw, then reports, then value or effect, else nothing. The differ's library facts (FirstOrDefault, DeclaringSyntaxReferences elements and GetSyntax non-null, located/IsInSource false on null, `0 ≤ w_len`) are hypotheses of every lemma. Coverage is stated over the literals with those facts and follows the rows' decision tree; infeasible leaves close by `simp_all`/`omega` on the facts. Per-iteration units (`foreach` from `translator --per-iteration`): the element is a lemma variable and `params` any pre-iteration state; rows and coverage are over one iteration; if no row's new outcome throws, `body_nothrow` (from coverage and rows) is lifted by `W.run_nothrow` to `loop_nothrow` (any length, any state transition).
- Bridge mode (any other rows, e.g. the contract fixture): typed models, literals via `--bridge`, coverage over bridged propositions or free Booleans (`decide`).

Interface (Rust)
- `emit::{parse_model, parse_rows, parse_bridge}`, `certify(&old, &new, &rows, &bridge, out, &Options) -> UnitResult`; `UnitResult::to_json()` is `lean.json`.
- `lean.json` extras (allowed by the schema): `coverage[].facts: [{key, text, lean, rows}]` (the contract field the validator checks against `scope.assumptions` library facts): the library facts every lemma of the unit takes as hypotheses, keyed and worded as `differ::exec::FACTS`. Every lemma takes all of them, so all rows and coverage are listed as relying on each. The differ's per-row fact use (`detail.json` `libraryFacts`) is what z3 used, not what the Lean proof uses, so it is not used to narrow the list; `loops: [{unit, property: "no-exception", version: "new", perIteration, lifted, reason, file, carried: {names, lean: "not-checked", note}}]`: carried loop state (`carriedNames`) is compared by the solver only; Lean covers each row's outcome for one iteration and the no-exception lift, and `lean.json` says so (`CARRIED_NOTE`).
- States `checked`, `model-checked`, `not-checked`; `wording(state)` gives the page text. Identical rows (`row: null`) are checked but not listed in `lean.json`.
- `proofs::ProofSource`, `proofs::Recorded { dir }` reads `<dir>/<recording_key("lean-proof", prompt, schema)>.json`, `response.proof`; no file means no call.
- `fold::FOLD_LEMMAS`, `fold::lift_nothrow(...)`; `check::run_lean`, `check::lean_version`. Lean runs one process at a time.

Deviations and fallbacks
- Why real 2283 failed before: the real models use `seq`, effect calls, nullable references of any sort and `none`/`isnull` on non-option sorts. The typed emitter rejected `seq` (L1), and the bridge's typed propositions did not fit. Differ mode fixes this here. The differ's bridge is now unused for differ output, and the translator needs no change.
- The differ's facts are re-derived from opaque symbols, as `differ::exec::FACTS` (GetSyntax for any number of arguments); a test pins the list.
- Coverage proves that the rows cover every input; dependent literals are settled by the facts. The link to the C# code is the translator's.
- Claims compare outcome tags (texts differ from model report names).
- Facts are pinned to the differ by key, text and SMT template; the Lean forms in `opaque_facts` are hand-matched to those templates. A nested `foreach` makes the unit not-checked (L1).
- Time limit is per file (30 s × theorems); seconds per row are the file's wall time. Coverage gets 4M heartbeats; the wall clock still applies.
- Fallbacks: T6, L1, L2 (`simp_all`, `split`, `omega` ladder), L3, L4, L5 (`FALLBACKS.md`).
