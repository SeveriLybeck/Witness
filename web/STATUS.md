Section interface
- `src/sections/<name>/index.tsx` exports `sections: SectionModule[]`; `SectionModule = { slot, Component, headline? }`, slot one of `review proof playground map decide signoff` (group 18 registers `review`, `decide`, `signoff`). A slot registered twice throws. Do not edit `package.json`; tests go in `src/sections/<name>/*.test.tsx`.
- Shell draws each slot's `<section>`, its `h2` (number for 1–3, title, `headline(data)`, state if not ready) and folding; `Component` gets `{ data: BundleData, state: SectionState }` (state from `bundle.sections`: decide/signoff ← `rules`).
- Import everything from `src/shell` (index.ts): `useShell()` → `data, source, selection {difference, block}, selectDifference(id), focusBlock(id), highlight {file, blocks}, highlightFile, code, openCode({file, line, side?}), closeCode, folded, setFolded(slot, bool), commands, shownParts, folderCounts`; `useCommands([{id, label, key?, run}], deps)`; components `Loc`, `DiffNumber` (`data-cite="diff:n"`), `LevelGlyph`, `Sheet`; helpers `blocksInFile changedLines firstChange levelOf basename`; tokens.
- `BundleData`: `key, bundle, records` (every record by name, `null` if absent) plus typed `files parts blocks differences levels`.
- Files index: `files[].history {folder, undeclared, reviews}` (D44) shows `undeclared` beside its folder when > 0, aria-label `<n> undeclared before`; `folderCounts` overrides.
- `DataSource`: `bundles() record(key,name) fileText(commit,path) request(method,path,body,headers?)` (headers e.g. `Authorization` for submit) and optional `folderCounts(key)`; gateway calls (sessions, playground) go through `source.request`.
- Tests: `test/harness.tsx` gives `fixtureSource(change, {onRequest, folderCounts})`, `fixtureData`, `renderInShell(change, data => node)`, `renderPage(change, {sections})` over `contracts/fixtures/<change>/`.
- CSS: shell styles are `src/shell/shell.css` (injected by `installStyles`); use only `var(--fs-*)`, `var(--s-*)`, colour tokens, `var(--motion)`. Labels go in a copy deck checked like `src/shell/labels.ts`.
